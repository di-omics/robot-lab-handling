# Deviations and incomplete takes

This release includes 61 Dream-1 take records for 45 distinct assigned task-layout pairs. All 45 pairs have a terminal score. The frozen criteria awarded 7 passes. 16 interrupted attempts are recorded, including retries. Per-task denominators count completed takes. [Frozen protocol](PROTOCOL.md). [Run table](runs/2026-11-18-zero-shot/results.md).

On tube handover, layout 102 met the frozen rule after the right hand picked up the tube itself. The left hand never held it. The run table retains the protocol pass, and a stricter handover interpretation would remove that pass. The lower plate hotel's alignment stage can also be reached by sliding the plate along the table, so that partial stage does not establish a lift. On rack carry, layout 101 passed after a level lift at 18 s, but the rack was then set down and later reached the mat half-lifted and tilted. The frozen rule asks for a level lift at some point and the rack at rest on the mat, so the pass stands.

A network interruption and a service refusal account for some incomplete takes. The service refused the waste-bin instruction on layout 102 after previously accepting the same wording on layout 101. The first-run protocol permits one infrastructure retry on the same layout. A refusal is a separate interpretation choice and can be counted as a failed attempt in a sensitivity analysis. The network failed a second time during the retries (name lookups failed between about 18:20 and 19:00 PST on 2026-11-18) and the app running them restarted at 19:00, so 3 pairs needed a third attempt. That is more than the one retry the protocol permits. The same rule was applied to every pair: retry until a take completes, and never retry a completed take. On its retry, the waste-bin task on layout 102 was not refused and passed. Taking the refusal as that layout's result instead would make the task 1 of 3 rather than 2 of 3. Original error classes and messages are preserved in the release with home directories displayed as `~/`.

The Fable comparator was stopped at the operator's request before receiving any terminal score. Its three interrupted traces remain in the paired report with their counts and elapsed simulation times. [Paired results](runs/2026-11-18-camera-comparison/RESULTS.md).
